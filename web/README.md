# Video Downloader - Web Frontend

React + Vite single-page application built with Tailwind CSS.

## Features
- 🔑 **Auth UX**: Login, Registration, Verification, Password Reset.
- 🎨 **Top-Right Profile Menu**: Email badge with dropdown menu (Home, Settings, History, Logout), click-outside listener, keyboard accessible (`Esc` key).
- 📹 **Clean Downloader Interface**: Centered URL input, Search & Download controls, loading indicators, video preview card.
- ⚙️ **Settings & History**: Account management, preference configuration, paginated download history (20/page).

## Development Setup

```bash
# 1. Install dependencies
npm install

# 2. Setup environment configuration
cp .env.example .env

# 3. Start development server
npm run dev
```

Server runs on `http://localhost:5173`.
