# Video Downloader - Mobile App (Expo React Native)

Cross-platform mobile application built with Expo and Expo Router.

## Features
- 🔐 **Secure Storage**: Device authentication token management using `expo-secure-store`.
- 📱 **Clean Mobile UX**: Top bar with brand logo and top-right email profile icon.
- 📋 **Profile Dropdown Menu**: Touch-friendly navigation (Home, Settings, History, Logout).
- 📹 **Video Downloader**: Full-width URL input, search, preview, and download actions.

## Quick Start

```bash
# 1. Install dependencies
npm install

# 2. Start Expo dev server
npx expo start
```

Press `w` to run in web browser, or scan QR code with Expo Go on Android/iOS.
